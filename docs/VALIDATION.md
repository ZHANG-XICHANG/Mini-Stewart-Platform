# 整理與驗證紀錄

## 主版本

- `stewart_control_gui.py` 保留維護者提供的新上位機原始碼。
- `firmware/ESP32C6_PCA/` 取自維護者提供的「控制系統/ESP32C6_PCA」，包含 ino 與必要 h。
- 已靜態確認 460800 baud、`$P` 六軸順序、旋轉單位 degree、換行分隔，以及 `$V,0` 靜默命令。
- 未於本次整理編譯或燒錄 ESP32，也未驗證實際串列收發與平台運動。

## 舊版相容介面

- 四項自動測試通過：封包解碼與量化誤差、不可達／非有限姿態拒絕、最新目標重送與停止、短寫入時停止傳送。
- 抽出的三個幾何計算方法與原視覺化的 AST 比對相同；此檢查證明抽取未改變計算，不代表原數學模型已驗證正確。
- 3D 視覺化無串列初始化及隱藏 Tk 視窗初始化通過。
- 相容面板使用 Tk 排程產生正弦目標；背景執行緒只處理串列傳送。

## 媒體與模型

- 公開副本保留原照片與 MP4，沒有生成或修改成果內容。
- 大型 GIF、重複 HEIC、CAD 鎖定檔、macOS 附加檔、原 EXE／APP 不納入公開清單。
- STEP／STL／SolidWorks 檔案僅整理複製，未做 CAD 開啟或列印驗證。
- 舊打包程式未重新建置；重新驗證後再作為 Release 附件。

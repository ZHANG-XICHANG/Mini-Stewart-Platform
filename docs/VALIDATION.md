## 舊版二進位相容面板

以下自動測試針對 `legacy/binary_pca9685`，不代表主版本韌體的測試結果：

1. 封包解碼符合接收器映射，量化誤差在一個編碼步距內。
2. 拒絕不可達姿態及 NaN／Infinity 輸入。
3. 只重送最新有效目標，並能停止傳送。
4. 串列短寫入時停止後續傳送。

四項測試均通過。測試使用假串列埠，不會驅動硬體；相容面板尚未實機驗證。

從專案根目錄進入測試目錄後執行：

```powershell
cd legacy/binary_pca9685
python -m unittest discover -s tests -v
```

共用幾何模組的三個計算方法與原視覺化方法通過 AST 比對，確認抽取時保留原計算邏輯。3D 視覺化與相容面板亦通過無硬體的初始化檢查；這些檢查不衡量機構定位精度。

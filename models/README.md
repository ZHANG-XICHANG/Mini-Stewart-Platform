# 3D 模型

| 目錄 | 內容 | 用途 |
| --- | --- | --- |
| `stl/` | 大平台、底座、控制盒、緊箍，共四個 STL | 匯入切片軟體製作零件 |
| `step/` | `組合件1.STEP` | 在支援 STEP 的 CAD 軟體檢視組合模型 |
| `solidworks/` | SLDASM 組合件與 SLDPRT 零件 | 編輯原生設計 |

開啟 `solidworks/組合件1.SLDASM` 時，請保留各零件的檔名與相對位置，以便解析組合件引用。列印前依使用的伺服、連桿與緊固件確認尺寸單位、配合間隙、列印方向及材料。

檔案格式與內容清單不代表所有 CAD 軟體或印表機皆已測試相容。
